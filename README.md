\# GraphicsEditor



\## Project Description



GraphicsEditor is a menu-driven 2D Graphics Editor developed in C. It uses a 2D character array as a drawing canvas. Empty spaces are represented using `\_` and graphical objects are drawn using `\*`.



\## Features



\* Draw Rectangle

\* Draw Line

\* Draw Triangle

\* Draw Circle

\* Delete Objects

\* Modify Objects

\* Display Canvas

\* Menu-Driven Interface



\## Technologies Used



\* C Programming Language

\* 2D Character Arrays

\* Functions

\* Structures (optional)

\* Git and GitHub



\## How to Compile



```bash

gcc main.c graphics.c -o editor

```



\## How to Run



```bash

./editor

```
